# AGENT.md

Guidance for AI agents (and people) working in this repository.

## What this repository is

An overview of the [CLARIN.SI repository](https://www.clarin.si/repository/xmlui/) from the point of view of AI development. Every current resource is sorted by where it helps in the model lifecycle, with its size, languages and licence. Slovenian and the other South Slavic languages come first, but all languages are covered.

It is published with GitHub Pages (default Jekyll rendering of the Markdown) at <https://clarinsi.github.io/clarinsi4ai/>.

## Layout

| Path | What it is |
| --- | --- |
| `README.md` | Overview page: summary, stage table, language coverage, key findings, gaps, how to read the pages, method |
| `01-pretraining.md` … `06-models-tools.md` | One page per lifecycle stage: pre-training, speech and multimodal, post-training, evaluation, lexical and knowledge, models and tools |
| `img/*.svg` | Static charts: one bar chart per stage and `coverage.svg` (resources per language and stage) |
| `clarinsi_ai_catalogue.xlsx` | Full catalogue, one row per resource, including superseded versions. Sheets: `Catalogue`, `Summary`, `Notes` |
| `slides/` | An 80-minute reveal.js talk: `index.html`, `theme.css`, `slides.pdf`, vendored `reveal/` (5.1.0) and `img/clarinsi-logo.png`. See `slides/README.md` |

The source data, `clarinsi.tsv` (the CLARIN.SI DSpace export of 14 October 2026, 1,291 records), is not in this repository. Two ParlaSpeech 4.0 records were added to it by hand, which gives the 1,293 records cited on the pages.

The pages, charts and spreadsheet were first generated by Python scripts that are not in this repository either. The Markdown files are now edited by hand and are the source of truth. Do not regenerate them from the export, because that would overwrite manual edits, such as the Slovenian sizes filled in for multilingual corpora.

## Editing rules

### Links

- Link back to the overview with `[← Overview](./)`, never `README.md`, because GitHub Pages serves `README.md` as raw Markdown.
- Link between stage pages with their `.md` file names. Jekyll turns them into `.html`.
- Each resource links to its handle, `http://hdl.handle.net/11356/NNNN`. When several versions of a resource exist, link the latest visible one.

### Tables

- Every stage table has five columns: `| Resource | Languages | Size | Licence | Year |`.
- Long tables are split under two `####` headings. The first lists Slovenian resources, including multilingual ones that contain Slovenian; the second lists all other languages. Short tables are not split.
- Rows are sorted by size, largest first.
- **Pre-training page only.** A multilingual resource appears twice:
  - in the first table as `[Title](handle) · Slovenian part`, with language `sl` and the size of its Slovenian part;
  - in the second table, `Other languages, and multilingual resources in full`, with its full size and all its languages.
  - Mark estimated sizes with `≈` and explain how each was estimated in a "Sizes marked ≈ are estimates: …" line under the table.
  - If the Slovenian size is unknown, write `not stated` and put the row at the end of the table. Never guess a number.
- **Languages.** Use ISO 639-1 codes where they exist (`sl`, `hr`, `sr`, `bs`, `mk`, `bg`, `en`), otherwise ISO 639-3 (`cnr` for Montenegrin). For six or more languages, write `N languages`.
- **Sizes.** Give words where the record has them, otherwise tokens; give hours for speech; otherwise use the unit the record uses. Write them as `2.6B words`, `771.9M words`, `83.3k words`, `1,067 h` or `3.1M sentence pairs`.
- **Licences.** Use the short labels: `CC0`, `CC BY`, `CC BY-SA`, `CC BY-NC-SA`, `ACA (BY-NC)`, `CLARIN.SI web-corpus licence`, `MULTEXT-East (NC)`, `none, no files`.

### What is in and what is left out

- **One entry per resource.** Versions are collapsed to the latest visible version, and hidden records are left out.
- **Superseded releases are left out of the pages and all counts.** They stay in the spreadsheet, with the status `superseded by …`. The current list:
  - Šolar 2.0 (by Šolar 3.0)
  - ssj500k (by SUK)
  - hr500k 1.0 and SETimes.SR 1.0 (by their 2.0 versions)
  - Gos 1.1 and Gos VideoLectures (by Gos 2.1)
  - the KAS 1.0 sub-corpora (by KAS 2.0)
  - all ParlaSpeech releases before 4.0
  - the monolingual MaCoCu corpora for sl, hr, sr, bs, mk, cnr and bg, because CLASSLA-web 1.0 is a cleaned version of them. The English-paired MaCoCu corpora are independent and stay in.
- **ParlaSpeech 4.0** is an ordinary, available resource. It has two records, transcriptions (11356/1885) and audio (11356/1889), shown as one row per language on the speech page, under CC BY-SA. Do not describe it as new, pending or special.

### Licence tiers

These are used in all "open" counts.

| Tier | Licences |
| --- | --- |
| Open (training and commercial use) | CC0, CC BY, CC BY-SA, Apache, MIT, GPL |
| Non-commercial | CC BY-NC variants, MULTEXT-East |
| Restricted | ACA (including ACA BY-NC), CLARIN.SI web-corpus licence |
| No licence | Records without files, which describe resources hosted elsewhere |

### Volume estimates

- **Speech hours.** Each record's stated duration is counted once, using hours, else minutes, else seconds; never add them together. Transcript-only releases and resources derived from other recordings (SloPhonSeg, ROG-Dialog) are not counted.
- **Pre-training words, overlap removed (≈ 53B).** Records that repackage other corpora are excluded:
  - metaFida
  - MaCoCu-Genre
  - the CLASSLA-web 1.0 and older South Slavic web crawls, superseded by CLASSLA-web 2.0
  - BERTić-data
  - ParlaMint.ana and ParlaMint-en
  - Gigafida and Trendi
  - the cc-subsets, KAS-Abs and PDRS
- **Pre-training words, all records (≈ 114B).** The plain sum over all pre-training records, overlaps included.
- **Per-language pre-training chart (`img/pretraining.svg`).** This is a rough estimate over the overlap-removed set:
  - CLASSLA-web 2.0 is split by the per-language sizes its record states;
  - TURK, Kranjska and yu1Parl are split by the language shares their records state;
  - other multilingual records are split evenly across their languages.

## Keeping numbers consistent

The same figures appear in several places, so a change to the content usually means editing all of them:

1. `README.md`: summary paragraph, stage table, language coverage, key findings and method.
2. The lead paragraph of the affected stage page.
3. The chart SVGs in `img/`. These are static files, so edit the `<text>` and `<rect>` elements by hand. The title states the finding and must agree with the bars.
4. The slides (`slides/index.html`), and then `slides/slides.pdf`. Several slides repeat the headline numbers.
5. The `Summary` sheet in `clarinsi_ai_catalogue.xlsx`.

## Slides

- All slides are Markdown inside the `<textarea data-template>` in `slides/index.html`. A line containing only `---`, with blank lines around it, starts a new slide. Lines after `Note:` are speaker notes.
- Layout classes (`cols`, `cards`, `stats`, `callout`, `tag`, `minibars`) are defined in `theme.css`. Markdown is not parsed inside HTML blocks, so use HTML tags there.
- Charts are loaded from `../img/`, so a change to a chart SVG also changes the slides.
- To export a new PDF, open `slides/index.html?print-pdf` in Chrome and print with layout *Landscape*, margins *None* and *Background graphics* on. A script hooked to `pdf-ready` repeats the logo and footer on every page. Check that both appear.
- Keep the talk at about 40 slides (80 minutes including questions). Pre-training and speech get the most time; lexical resources and models are covered briefly.

## Style

- Write in plain British English (licence, normalisation), with short sentences and no marketing language.
- Use sentence-case headings.
- Use commas as thousand separators (`1,032`) and an en dash for ranges (`2017–2025`).
- Chart titles state the finding with its number. South Slavic languages are blue (`#2f6fd6`) and other languages grey (`#c9c7bd`).
- Say "not stated" rather than estimating a figure that has no basis in the record.
